运行方式

自动化
Linux native 下请先在「运行方式」保存 sudo 密码；保存后启动、安装和同步会自动提权，不再弹窗。安装完成后会自动启动一次（可关闭）。
维护与帮助
Linux 依赖包含 xvfb / x11vnc / openbox / dbus 等；安装、版本选择与镜像在「下载与安装」里。
